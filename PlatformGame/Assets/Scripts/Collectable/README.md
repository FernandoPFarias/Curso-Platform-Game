# Sistema Collectable

## O que é?
Scripts responsáveis por colecionáveis: moedas, vidas extras, health pickups, etc.

## Como configurar
- Adicione os prefabs de colecionáveis na cena.
- Configure valores (quantidade, tipo) no Inspector.

## Integração
- Conecta com GameManager para atualizar moedas, vidas, etc.
- Atualiza UI ao coletar itens.
- Integração com FMODAudioManager para sons de coleta.

## Dicas
- Use prefabs para facilitar a reutilização.
- Teste colisão e feedback visual/sonoro.
